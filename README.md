# Task Manager API

A REST API for managing personal tasks, built with Python, Django REST Framework and PostgreSQL.

## Features

- User authentication
- CRUD operations for tasks
- User-specific task access
- Django REST Framework ViewSets and Routers
- Permissions
- Pagination
- Filtering
- Search
- Ordering
- Serializer validation

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Git / GitHub
- Postman

## API

The API provides endpoints for creating, viewing, updating and deleting tasks.

Users can access only their own tasks.

## Project

This is a personal learning project created to practice backend development with Django REST Framework and PostgreSQL.
